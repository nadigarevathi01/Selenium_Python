Page Object Model (POM) - Clean separation of test logic and UI elements
✅ Pytest Integration - Powerful test execution with fixtures and parameterization
✅ Modular Design - Easy to maintain and scale as your project grows

📁 Key Components Explained:
🔹 pages/ - Contains all page object classes with locators and methods
🔹 tests/ - Test cases organized by functionality with pytest fixtures
🔹 utils/ - Driver management, configuration readers, and helper utilities
🔹 reports/ - Generated HTML reports
🔹 screenshots/ - Automated failure screenshots for debugging
